# Hands-On Machine Learning with PyTorch — Notebooks

Personal notebooks and exercises following along with *Hands-On Machine Learning*, adapted to PyTorch.

## Structure

Each chapter/topic lives in its own numbered folder, e.g.:

```
02_end_to_end_machine_learning_project/
├── datasets/
│   ├── housing.tgz
│   └── housing/housing.csv
└── explore_and_visualise_data.ipynb
```

## Getting started

1. Create and activate a virtual environment.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Launch Jupyter and open the notebook for the chapter you want:
   ```bash
   jupyter lab
   ```

## Contents

- **02_end_to_end_machine_learning_project** — exploring and visualising the California housing dataset (end-to-end ML project workflow).

Datasets are included directly in this repo for convenience/reproducibility. For larger future chapters, consider downloading data at runtime instead of committing it.
